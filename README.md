# Learned image compression

Shared repository: https://github.com/ricardotk002/learned-img-compression

- [Ballé, Laparra & Simoncelli (ICLR 2017)](balle2017/README.md): baseline implementation.
- [Initial Kodak results](balle2017/RESULTS.md): evaluation tables and comparison figures.

Run commands from this repository root. No datasets or trained weights are bundled.

Use system-wide Python for this project, as requested by the project owner.
Do not create a project-specific `.venv`. GPU setup and verification instructions
are in the baseline README.
