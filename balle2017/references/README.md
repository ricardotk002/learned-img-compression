# Reference material

Downloaded 2026-10-29 for local inspection:

- `paper.pdf`: https://arxiv.org/pdf/1611.01704 (v3, ICLR 2017).
- `project.html`: https://www.cns.nyu.edu/~lcv/iclr2017/
- `compress.m` and `uncompress.m`: authors' released grayscale transforms.
- `weights/gray/lambda-000512/*.mat`: numeric pretrained transforms from the
  authors' `parameters/gray/lambda-000512/` directory.

Downloads are ignored by Git. Source links and our independent implementation
are tracked. No downloaded code is executed, no untrusted pickle files are loaded.
The authors note differences between the released MATLAB and original Python
boundary handling, and the release omits their CABAC encoder.
